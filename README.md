# 🌙 ALMAS DE POMBAGIRA 🌙
**Ecossistema Digital 3D • 28 Plataformas • Presença Global**

![Foto do Projeto - Alê](https://raw.githubusercontent.com/pombagiras/melusine/refs/heads/main/Al%C3%AA%20(3)%20(3)%20(1).png)

> Dashboard interativo 3D com visualização completa do ecossistema digital das **Almas de Pombagira**. Gráfico em Three.js, partículas animadas, glassmorphism e 28 redes sociais ativas.

---

## ✨ Funcionalidades

- **Gráfico 3D Pie Chart** interativo (Three.js + OrbitControls)
  - Fatias por categoria (Video, Social, AI, Messaging, etc.)
  - Animações automáticas, estrelas, anéis flutuantes e partículas
- **Lista de 28 redes sociais** com:
  - Ícones personalizados (Bluesky, X, Threads, Kwai)
  - Percentual de presença
  - Progress bars animadas
  - Clique direto para abrir cada perfil
- **Partículas de fundo** douradas animadas
- **Design futurista** com glow, gradients e glassmorphism
- **Totalmente responsivo** (mobile + desktop)
- **Header com stats** e links oficiais (Bio Site, Linktree, Canva, GitHub)

## 🚀 Como Usar

1. Copie **todo o código HTML** acima
2. Salve como `index.html`
3. Abra diretamente no navegador (Chrome/Firefox recomendado)
4. Gire o gráfico 3D com o mouse e clique em qualquer rede social!

> Não precisa de servidor. Funciona offline!
